# Vёska 🌾

Твой цифровой хутор спокойствия / Your digital village of peace.

**Приложение:** https://makemamamad.github.io/veska/

Мобильное веб-приложение для спокойных вечеров. Работает без регистрации и внешнего сервера, хранит прогресс в Local Storage. Русский и английский интерфейс.

## Возможности

- Онбординг: приветствие, язык, два вопроса. Любимый звук становится фоном сеансов.
- **Хутар:** интерактивная анимированная карта. Четыре завершённых сеанса последовательно открывают хату, млын, свiран и кострище. Нажатие на объект включает его звук.
- **Гукі:** независимые переключатели и громкость дождя, костра, ночного леса и ветра; одновременное смешивание.
- **Спакой:** стрик завершённых вечеров, минуты прослушивания, достижения, язык и рассказчик, ссылка на обратную связь в GitHub Issues. Подписка обозначена как будущая функция.
- Четыре оригинальные трёхминутные истории, текст на экране и системная озвучка, интерактивный фонарь, пауза и подтверждение выхода без награды.
- Режим сна: 15 / 30 / 45 минут или бесконечно, пауза, уменьшение громкости за последние 10 секунд. Таймер основан на абсолютном времени; затухание планируется непосредственно в Web Audio.
- Кеш приложения для повторного открытия без сети, manifest, доступные названия контролов, клавиатурное управление, reduced motion, адаптивная вёрстка.

## Запуск и проверка

Нужен Node.js 20+. Установка пакетов не требуется: runtime и тесты не используют npm-зависимости.

```sh
npm run dev
# http://127.0.0.1:4173
npm test
npm run build
# готовая статическая версия — dist/
```

Открывать через HTTP(S), не через `file://`. GitHub Pages настроен на ветку `main`, папку `/ (root)`, файл `.nojekyll` отключает Jekyll. Изменения в main автоматически публикуются. Для другого статического хостинга загрузите содержимое `dist/`.

## Структура

- `src/app.js` — экраны, события, жизненный цикл сеанса и таймера.
- `src/state.js` — нормализация, прогресс, календарный стрик, таймер.
- `src/audio.js` — четыре процедурных звуковых слоя на Web Audio API.
- `src/art.js` — карта и анимированные объекты SVG.
- `src/content.js` — русский/английский текст и оригинальные истории.
- `src/style.css` — адаптивный интерфейс, эффекты, reduced motion.
- `sw.js` — кеш приложения для повторного посещения без сети.
- `tests/` — регрессионные проверки состояния и таймера.

## Состояние и ограничения первой версии

Ключ Local Storage — `veska.v1`. `level` соответствует `Current_Level`: 1 — пустая земля, 2 — хата, 3 — млын, 4 — свiран, 5 — костёр. Повторные истории после уровня 5 не меняют открытые объекты. Награда выдаётся только после 180 активных секунд. При уходе со страницы истории сеанс ставится на паузу. Стрик учитывает локальные календарные дни завершения сеансов, а не медицинский показатель стресса. Минуты суммируются, когда аудиоконтекст действительно работает и хотя бы один слой слышен.

Звуки — **синтезированные звуковые пейзажи**, а не полевые записи из указанных мест. Рассказчик — SpeechSynthesis устройства, его качество и наличие русского/английского голоса зависят от ОС; при недоступности озвучки остаётся текст. Для production можно заменить звук лицензированными бесшовными записями и профессиональной озвучкой.

Браузер не может гарантировать воспроизведение после блокировки телефона, скрыть системную строку на всех устройствах или самостоятельно закрыть приложение. Fullscreen запрашивается там, где поддерживается; таймер останавливает звук и оставляет тёмный экран. Надёжное фоновое аудио для App Store / Google Play потребует нативной оболочки и интеграции с аудиосессиями ОС. Это веб-MVP, не опубликованное нативное приложение.

Прогресс не синхронизируется между устройствами и удаляется при очистке данных сайта. В приватном режиме сохранение может быть запрещено — приложение сообщает об этом. Приложение не отправляет анкету или прогресс на сервер. Шрифты загружаются с Google Fonts (обычный сетевой запрос с IP-адресом), при отсутствии сети используются системные. GitHub Pages обрабатывает запросы к сайту по своей политике конфиденциальности.
