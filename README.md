# Vёska 🌾

Твой цифровой хутор спокойствия / Your digital village of peace.

**Приложение:** https://makemamamad.github.io/veska/

Мобильное веб-приложение для спокойных вечеров. Работает без регистрации и внешнего сервера, хранит прогресс в Local Storage. Русский и английский интерфейс.

## Возможности

- Онбординг: приветствие, язык, два вопроса. Любимый звук становится фоном сеансов.
- **Хутар:** интерактивная анимированная карта. Хата видна в первый день; завершённые истории открывают млын, кострище и свiран. Нажатие на объект включает его звук.
- **Гукі:** независимые переключатели и громкость дождя, костра, ночного леса и ветра; одновременное смешивание.
- **Спакой:** стрик завершённых вечеров, минуты прослушивания, достижения, язык и рассказчик, ссылка на обратную связь в GitHub Issues. Подписка обозначена как будущая функция.
- Четыре оригинальных двадцатидвухминутных сеанса, текст на экране и записанная озвучка ElevenLabs, интерактивный фонарь, пауза и подтверждение выхода без награды.
- Режим сна: 15 / 30 / 45 минут или бесконечно, пауза, уменьшение громкости за последние 8 секунд. Таймер основан на абсолютном времени; затухание планируется непосредственно в Web Audio.
- Кеш приложения для повторного открытия без сети, manifest, доступные названия контролов, клавиатурное управление, reduced motion, адаптивная вёрстка.

## Запуск и проверка

Нужен Node.js 20+. Установка пакетов не требуется: runtime и тесты не используют npm-зависимости.

```sh
npm run dev
# http://127.0.0.1:4173
npm test
npm run build
# готовая статическая версия — dist/
```

Открывать через HTTP(S), не через `file://`. GitHub Pages настроен на ветку `main`, папку `/ (root)`, файл `.nojekyll` отключает Jekyll. Изменения в main автоматически публикуются. Для другого статического хостинга загрузите содержимое `dist/`.

## Структура

- `src/app.js` — экраны, события, жизненный цикл сеанса и таймера.
- `src/state.js` — нормализация, прогресс, календарный стрик, таймер.
- `src/audio.js` — шесть записанных фоновых слоёв на Web Audio API.
- `src/narration.js` — локальные MP3-фрагменты рассказчика, загрузка и пауза с сохранением позиции.
- `assets/` — природные петли и озвучка MP3; WAV-исходники для повторной обработки.
- `audio-credits.html` — источники, обработка и лицензии.
- `src/art.js` — карта и анимированные объекты SVG.
- `src/content.js` — русский/английский текст и оригинальные истории.
- `src/style.css` — адаптивный интерфейс, эффекты, reduced motion.
- `sw.js` — кеш приложения для повторного посещения без сети.
- `tests/` — регрессионные проверки состояния и таймера.

## Состояние и ограничения первой версии

Ключ Local Storage — `veska.v1`. `currentDay` — номер следующего вечера строительства; `unlocked` определяет видимые объекты. `level` сохранён для совместимости. Повторные истории после уровня 5 не меняют открытые объекты. Прогресс сохраняется после естественного завершения всех голосовых фрагментов; в режиме без голоса — после 840 активных секунд. Яркого экрана поздравления нет. До 9-й минуты уход со страницы ставит сеанс на паузу; далее аудиочасы продолжают сеанс, пока браузер разрешает воспроизведение. Стрик учитывает локальные календарные дни завершения сеансов, а не медицинский показатель стресса. Минуты суммируются, когда аудиоконтекст действительно работает и хотя бы один слой слышен.

Звуки природы — записи CC0 с OpenGameArt и Freesound, обработанные и зацикленные с плавными стыками. Названия мест художественные: записи не сделаны в Беларуси. Исходники MP3; WAV используется для точного зацикливания без дополнительного сжатия и не улучшает качество исходника. Четыре петли занимают около 4,26 MB в MP3 320 kbps, загружаются только при включении и кешируются после прослушивания.

**Истории с elevenlabs.io:** русский голос Igor — Calm & Warm Bedtime Storyteller; английский Rowan — Gentle, Soft-Spoken & Warm. Модель Eleven Multilingual v2, скорость 0.82, stability 0.5, similarity 0.75, style 0, speaker boost off. Оригинальные MP3 44.1 kHz / 128 kbps разделены по паузам без повторного сжатия. 32 фрагмента соответствуют четырём абзацам каждой из восьми историй. Версии `-warm.mp3` обработаны: high-pass 65 Гц, +2 dB около 150 Гц, low-pass 8 кГц, компрессор 2.5:1, целевой RMS −23 dBFS с ограничением пиков. Это обработка существующего голоса, не новая запись шёпотом. Границы предложений размечены по паузам и хранятся в `src/voice-cues.js`.

**Некоммерческая демонстрация:** озвучка сгенерирована 2 октября 2026 на бесплатном тарифе ElevenLabs и не имеет коммерческой лицензии. Перед монетизацией перегенерируйте или замените её на записи с подходящими правами. Атрибуция elevenlabs.io указана в названии приложения, сеансах и credits. Условия: https://help.elevenlabs.io/hc/en-us/articles/13313564601361-Can-I-publish-the-content-I-generate-on-the-platform . Лицензия CC0 на природные записи не распространяется на озвучку.

В приложении нет API-ключей и системного SpeechSynthesis. Секреты ElevenLabs не нужны пользователю: воспроизводятся готовые файлы из репозитория. При недоступности записи остаётся текст и сообщение об ошибке. Для обновления голоса замените версии `-warm.mp3` и заново разметьте длительности и границы предложений в `src/voice-cues.js`. При первом запуске без сети ещё не загруженные звуки недоступны.

Браузер не может гарантировать воспроизведение после блокировки телефона, скрыть системную строку на всех устройствах или самостоятельно закрыть приложение. Fullscreen запрашивается там, где поддерживается; таймер останавливает звук и оставляет тёмный экран. Надёжное фоновое аудио для App Store / Google Play потребует нативной оболочки и интеграции с аудиосессиями ОС. Это веб-MVP, не опубликованное нативное приложение.

Прогресс не синхронизируется между устройствами и удаляется при очистке данных сайта. В приватном режиме сохранение может быть запрещено — приложение сообщает об этом. Приложение не отправляет анкету или прогресс на сервер. Шрифты загружаются с Google Fonts (обычный сетевой запрос с IP-адресом), при отсутствии сети используются системные. GitHub Pages обрабатывает запросы к сайту по своей политике конфиденциальности.

## Микшер и мобильное воспроизведение

Голос: gain 0.9. Фон сеанса: gain 0.25 независимо от сохранённых настроек свободного микшера, fade-in 0→0.25 за 4 секунды. Все источники проходят через общий output GainNode: завершение сеанса, выход и остановка микшера запускают fade-out до нуля за 8 секунд. Таймер сна планирует последние 8 секунд затухания непосредственно на аудиочасах. Кнопка паузы остаётся паузой; запрос выхода показывает подтверждение без резкого обрыва звучания.

Каналы свободного микшера загружаются независимо. Поздняя загрузка не включает отменённый канал. Если сумма громкостей больше 100%, общий коэффициент микса уменьшается пропорционально, сохраняя соотношения каналов и запас до перегрузки. На первом этапе горизонтальный свайп по подсказке (или доступное нажатие кнопки) рассеивает туман: водяной шорох 8%. Фонарь на втором этапе: `interfaceClickUrl`, реальный щелчок выключателя, gain 0.4, однократно за сеанс.

Мобильная вёрстка использует динамическую высоту `dvh`, безопасные отступы вырезов экрана, прокрутку при длинном тексте и обычный масштаб браузера. Переходы используют прозрачность; reduced motion отключает анимацию.

## Вечер: 2 минуты дыхания + 20 минут сценария

- 0–2: без голоса. Десять циклов: вдох 4 с, задержка 4 с, выдох 4 с. Круг и подписи синхронизированы с аудиочасами и паузой; reduced motion оставляет только подписи.
- 2–5: голос и интерактивные туман / фонарь.
- 5–9: предложения истории с паузами 12 секунд, три необязательных касания деталей.
- 9–14: заданий нет, пять тихих фраз через минуту.
- 14–22: голос отключён, тёмный экран; таймер можно продлить.

Автоматический фон постепенно меняется на дождь и сверчков (на втором дне сохраняет ветер и скрип), если пользователь не настроил собственный микс. Ручные уровни и включённые каналы сохраняются и имеют приоритет над сменой фаз.

## Карта и личная атмосфера

`currentDay` сохраняется в `veska.v1` и зеркалируется отдельным ключом `currentDay`: 1 — Хата, 2 — Млын, 3 — Кострище, 4 — Свіран, 5 — все истории пройдены. Хата видна сразу. Завершение всех голосовых фрагментов через естественное `AudioBufferSourceNode.onended` открывает следующую локацию и сохраняет день; выход, остановка, пауза, пропущенная или не загрузившаяся фраза не дают награду. Повтор одного callback не увеличивает прогресс. В текстовом режиме без голоса завершение считается по окончании всей сюжетной фазы. Ограничения по календарной дате нет. Старые постройки сохраняются при миграции.

Второй день — «Старая мельница»: отдельная русская и английская запись с мельником и ночным ветром. Ссылки `voiceDay2Url`, `ambientWindUrl`, `ambientMillUrl` находятся в `src/day2.js`. Фон по умолчанию: чистый ветер 25% и деревянный скрип 15%, оба с fade-in 4 с и непрерывным PCM loop. В поздней фазе ветер растёт до 38%, скрип остаётся 15%. Выход плавно гасит весь звук за 8 с.

Панель с нотами и вкладка звуков показывают четыре базовых канала, а со второго дня ещё ветер и скрип. Ползунки 0–100% сохраняются. Настроенный микс с каналами мельницы восстанавливается при следующем сеансе. Настройка во время сеанса отменяет автоматическую смену уровней. Во время паузы микшер не возобновляет звук.


## Непрерывные петли и лёгкие сцены

После декодирования MP3 `src/loop-buffer.js` удаляет только почти нулевые края (до 150 мс) и соединяет конец с началом перекрытием 400 мс. Обработанный PCM-буфер зациклен одним AudioBufferSourceNode; JavaScript не перезапускает звук на каждом обороте. Дополнительное перекрытие не требует новых файлов или сетевых запросов. Внутренние тихие участки остаются неизменными.

Светлячки объединены в три группы с анимацией прозрачности (две на экранах до 700 px). На мобильных устройствах туман и дым статичны. Скрытые и находящиеся вне экрана сцены приостанавливают анимацию; смена фразы обновляет только текст, сохраняя графику. Анимации теней заменены на прозрачность/transform, без постоянного продвижения каждой частицы в отдельный слой.

Проверены ширины 320 px и горизонтальный экран 667×375: ползунки и кнопки таймера имеют область касания не менее 44 px по высоте, содержимое прокручивается без горизонтального переполнения. Реальная частота кадров и работа при блокировке требуют проверки на целевых телефонах.

## Динамический viewport

Главный `#app` имеет `height: 100dvh` с резервным `100vh`. Полноэкранные разделы используют `min-height: 100dvh` и могут расти по содержимому, поэтому длинный текст не обрезает управление. Прокрутка остаётся у документа. SVG-фон заполняет раздел через `preserveAspectRatio="xMidYMid slice"`; для фоновых элементов также задан `object-fit: cover`.

У фонового Web Audio источника явно заданы `loop = true`, `loopStart = 0`, `loopEnd = preparedBuffer.duration`. Один источник повторяет декодированный PCM-буфер с перекрытием стыков 400 мс. Обработчики `timeupdate` и перезапуск HTML audio не используются.
